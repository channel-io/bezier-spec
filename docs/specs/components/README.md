# 컴포넌트

1차 공개 명세의 검토 초안이다. 공통 설계 규칙과 플랫폼별 API를 분리한다. 명세 버전은 라이브러리 버전과 다르다.

| 명세                        | 공개 명세 버전 | 상태      | 확인한 구현             |
| --------------------------- | -------------- | --------- | ----------------------- |
| [Button](Button.md)         | 0.1.0          | 검토 초안 | Web 4.0.0-next.15 /beta |
| [IconButton](IconButton.md) | 0.1.0          | 검토 초안 | Web 4.0.0-next.15 /beta |
| [Spinner](Spinner.md)       | 0.1.0          | 검토 초안 | Web 4.0.0-next.15 /beta |

세 컴포넌트의 공통 기준은 [액션과 피드백](../foundations/action-and-feedback.md)을 따른다. iOS·Android 구현은 아직 대조하지 않았다. 이 목록에 없는 컴포넌트와 라이브러리 버전의 동작은 이 명세로 보장하지 않는다.
