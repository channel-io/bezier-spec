# 컴포넌트

등록된 공개 컴포넌트 명세가 아직 없습니다.

명세는 `Button.md`, `TextField.md`처럼 컴포넌트별 파일로 추가합니다. 이 이름들은 경로 예시이며 실제로 등록된 명세가 아닙니다.

각 문서에는 공통 사용 기준·상태·접근성과 [foundation](../foundations/README.md) 참조를 적습니다. 플랫폼 차이는 문서 안의 플랫폼별 절 또는 [플랫폼 보충 문서](../platforms/README.md)로 연결합니다.

공개 명세를 추가할 때 이 목록과 [llms.txt](../../../llms.txt)에 직접 링크를 추가합니다. [작성 양식](../../../templates/component.md)을 참고합니다.
