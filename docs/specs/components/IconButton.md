텍스트 없이 아이콘 하나로 액션을 제공한다. 툴바·반복되는 행의 컨트롤처럼 공간이 제한되고 아이콘의 뜻이 익숙한 경우에 사용한다.

## 선택 기준

- 아이콘만으로 결과를 이해하기 어렵거나 가장 중요한 주 액션이면 텍스트가 있는 [Button](Button.md)을 사용한다.
- 액션의 위계와 의미는 [액션과 피드백](../foundations/action-and-feedback.md)을 따른다.
- 아이콘 영역과 조작 가능한 버튼 영역을 구분한다. 플랫폼별 크기를 임의로 통일하지 않는다.
- 이동이 목적이면 링크 의미를 제공한다.

## 접근성

보이는 텍스트가 없으므로 액션을 설명하는 접근 가능한 이름을 제공한다. Web에서는 `aria-label` 또는 `aria-labelledby`를 지정한다. Tooltip이 보인다는 사실만으로 접근 가능한 이름이 생긴다고 가정하지 않는다.

비활성화 이유가 필요하면 비활성 요소에 마우스를 올리는 방법만으로 안내하지 않는다. 키보드와 보조 기술에서도 설명을 읽을 수 있게 한다.

## 상태

기본·비활성·처리 중 상태를 구분한다. 처리 중에도 액션의 이름과 상태를 이해할 수 있어야 한다. 동작을 설명하는 아이콘과 로딩 표시는 역할을 구분한다.
