작업이 진행 중이지만 완료 비율을 알 수 없을 때 사용하는 로딩 표시다.

## 선택 기준

- 진행률을 알 수 있으면 진행률 표시가 더 적합하다.
- 새 콘텐츠가 들어올 빈 영역의 형태를 미리 보여줄 필요가 있으면 skeleton 패턴을 고려한다. 이 문서는 특정 Skeleton 컴포넌트의 제공 여부를 보장하지 않는다.
- 가능하면 작업이 일어난 영역 가까이에 표시한다. 불필요하게 화면 전체를 막지 않는다.
- [Button](Button.md)·[IconButton](IconButton.md)에 로딩 API가 있으면 해당 API를 우선 사용한다.

## 표시와 접근성

짧은 로딩의 깜빡임을 피하고, 액션 후 응답이 300ms 이상 없으면 로딩 상태를 알리는 설계 기준을 적용한다. 이 지연은 애플리케이션에서 관리하며 Spinner 자체의 자동 표시 지연이 아니다.

Spinner는 클릭하거나 키보드 포커스를 받는 컨트롤이 아니다. 처리 중이라는 상태를 보조 기술에도 전달하고, 완료하면 불필요한 로딩 표시를 제거한다. 공통 기준은 [액션과 피드백](../foundations/action-and-feedback.md)을 따른다.
