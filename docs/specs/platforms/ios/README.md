# iOS

대상 공개 구현은 [BezierSwift](https://github.com/channel-io/BezierSwift)다.

현재 공개 명세 0.1.0은 검토 초안이며, Button·IconButton·Spinner의 iOS 구현 버전·API·치수·지원 상태는 대조하지 않았다. Web의 API나 지원 여부를 근거로 iOS 동작을 추정하지 않는다.

[공통 컴포넌트](../../components/README.md)와 실제 차이를 확인해 플랫폼 보충 문서를 PR로 제안할 수 있다. 해당 tag/commit과 확인한 동작을 함께 적는다.
